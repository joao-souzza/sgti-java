# Desafio — Sistema de Gestão de Equipe de Tecnologia (SGTI)

## Sobre o projeto

O SGTI é um sistema de gestão de funcionários de uma equipe de tecnologia, desenvolvido em Java como desafio prático durante meus estudos no curso Fundamentos do Java, da Rocketseat.

O projeto tem como objetivo aplicar conceitos de Programação Orientada a Objetos e Estruturas de Dados na construção de uma aplicação de gerenciamento executada via terminal.

## Funcionalidades

- Cadastro de funcionários;
- Listagem de funcionários cadastrados;
- Consulta dos salários finais;
- Identificação do funcionário com maior salário;
- Contabilização de funcionários por cargo;
- Pesquisa de funcionários pelo nome.

## Tecnologias e conceitos utilizados

- **Java:** linguagem utilizada no desenvolvimento.
- **POO:** encapsulamento e polimorfismo.
- **Enum:** representação dos cargos e opções do menu.
- **ArrayList:** armazenamento dos funcionários.
- **HashMap:** contabilização de funcionários por cargo.
- **Collections:** manipulação de coleções.
- **Tratamento de exceções:** validação de entradas e opções inválidas.

## Regras de bonificação

Cada cargo possui uma porcentagem específica de bonificação sobre o salário:

| Cargo | Bonificação |
|---|---:|
| Desenvolvedor (DEV) | 10% |
| Product Manager (PM) | 20% |
| DevOps | 15% |

## Como executar

1. Clone este repositório.
2. Abra o projeto em sua IDE.
3. Execute a classe `Main`.
4. Utilize o menu apresentado no terminal para interagir com o sistema.
